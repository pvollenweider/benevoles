# Ressources externes des vidéos

Les fichiers audio sous licence ne sont pas copiés dans le dépôt. Leur chemin local est fourni avec `VIDEO_MUSIC_PATH` dans `.env.video.local`.

## Musique du pilote

- Titre : **Tech House vibes**
- Artiste : **Alejandro Magaña (A. M.)**
- Fichier téléchargé : `mixkit-tech-house-vibes-130.mp3`
- Source : [Mixkit Free Stock Music](https://mixkit.co/free-stock-music/)
- Licence : [Mixkit Stock Music Free License](https://mixkit.co/license/#musicFree)
- Téléchargé le : 2 octobre 2026
- Fichier local attendu : MP3, hors du dépôt

Avant publication :

1. conserver le nom du fichier, le lien de téléchargement et une copie de la licence applicable au jour du téléchargement ;
2. vérifier que le canal de diffusion reste autorisé par la licence Mixkit ;
3. ne jamais distribuer le MP3 seul, le revendiquer comme une création propre ou l’ajouter aux sources publiques du projet ;
4. ne pas enregistrer le morceau ou la vidéo auprès d’un service de gestion automatisée des droits musicaux.

Les justificatifs de licence peuvent contenir des informations de compte : ils restent dans les archives privées, pas dans Git.
