# Voir qui est inscrit sur les créneaux

## roster-setting

Dans Paramètres, la section Qui est inscrit définit le choix proposé pour les futurs événements. Par défaut, ce réglage est activé. Les événements existants gardent leur propre valeur. Ouvrons un nouvel événement. La case est déjà cochée. Vous pouvez la décocher pour cet événement. Le rappel demande d’informer les bénévoles, y compris du comptage des places dont le nom reste masqué. Activer le réglage ne donne jamais leur accord à leur place.

## roster-publication

Retrouvons notre événement de démonstration. Dans ses réglages, la même option est activée. Vous pouvez la désactiver puis la réactiver. Sur Vérifier avant publication, une note rappelle ce qui sera visible et permet de modifier le réglage. Publions l’événement.

## roster-signup

Voici la page vue par un visiteur anonyme. Aucun bouton pour voir les inscrits, aucun nom. Choisissez un créneau, puis continuez. Renseignez votre prénom, votre nom et votre adresse email. Acceptez la convention et l’utilisation des données pour l’inscription. La case de visibilité est facultative et non cochée. Elle autorise les bénévoles confirmés et les membres invités par l’organisation à voir votre prénom et l’initiale de votre nom sur vos créneaux confirmés. Même sans nom affiché, votre place est comptée. Cochez cette case si vous le souhaitez, puis confirmez l’inscription.

## roster-confirm

Ouvrez le véritable email de confirmation. Suivez son lien personnel. La carte Qui est inscrit montre uniquement vos propres créneaux confirmés, avec les noms acceptés et le nombre des autres bénévoles. Votre demande du formulaire attend votre confirmation depuis ce lien. Cliquez sur Afficher mon nom. Pour consulter les autres créneaux, suivez Voir qui est inscrit sur les autres créneaux.

## roster-event

Sur la page de l’événement, le bouton Voir qui est inscrit se trouve à côté de Frise et Liste. Le lien personnel l’a ouvert activé. Passons en Liste. Sur votre créneau, la ligne commence par Avec toi. Sur les autres, elle commence par Sur ce créneau. Les personnes sans nom affiché sont comptées ensemble, sans préciser la raison. Passons en Frise. Les barres restent inchangées. Survolez un créneau : la ligne sous le graphique du jour montre les personnes de cette barre. La vue Liste permet de parcourir tous les détails au clavier.

## roster-invite

Un membre qui arrive par son lien d’invitation voit aussi le bouton, avant même de s’inscrire. Activez Voir qui est inscrit. En Liste, Aline apparaît avec son prénom et l’initiale de son nom, à côté du nombre des autres bénévoles. Ce lien est personnel : gardez-le pour vous.

## roster-existing

Bruno avait accepté l’ancien texte, limité aux bénévoles confirmés. Sur sa page personnelle, le bouton Montrer aussi mon nom aux membres invités propose un nouveau choix explicite. Cliquez sur ce bouton pour élargir cet accord. Sur le lien d’invitation, Bruno devient visible. Aucun ancien accord n’est élargi automatiquement.

## roster-withdraw

Revenons sur la page personnelle d’Aline. Cliquez sur Masquer mon nom. Sur la page ouverte par l’invitation, Aline a disparu ; sa place reste comptée. Ce retrait ne change pas son inscription. Pour terminer, voici la même page sans identification. Le bouton et les noms ont disparu. Rien non plus dans l’intégration à votre site ni sur les liens de groupe. Les mineurs connus ne sont jamais nommés. Les noms ne sont consultables que jusqu’à la fin de l’événement.
