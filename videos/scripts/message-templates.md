# Partir d’un modèle de message prêt à l’emploi

Ajouter un modèle de la bibliothèque, compléter les informations et vérifier l’email avant de l’envoyer aux bénévoles.

## Ouvrir la bibliothèque

Pour prévenir votre équipe qu'il va pleuvoir, vous pouvez partir d'un texte prêt à l'emploi. Dans les paramètres de l'organisation, ouvrez Modèles de messages, puis Ajouter des modèles. Les textes sont classés par catégorie. Repérez l'alerte pluie dans Météo et imprévus.

## Prévisualiser et ajouter

Cliquez sur Aperçu pour voir l'email tel qu'un bénévole le recevra, avec des valeurs d'exemple. Les mentions surlignées indiquent les informations à remplacer, comme l'heure et le lieu où s'abriter. Cliquez sur Ajouter à mes modèles. La mention Déjà dans mes modèles confirme l'ajout.

## Utiliser le modèle dans un événement

Dans les messages de votre événement, ouvrez Écrire aux bénévoles. Dans Partir d'un modèle, choisissez l'alerte pluie. Cliquez sur Utiliser ce modèle. L'objet et le texte apparaissent dans le formulaire.

## Repérer les informations manquantes

Demandez l'aperçu. Le message reste dans le formulaire. Le champ Message signale les informations à compléter. Vous pouvez les renseigner ici pour cet envoi. Corrigeons le modèle lui-même pour que l'équipe retrouve le texte complet.

## Adapter le modèle à la fête

Dans vos modèles, ouvrez Modifier. Indiquez qu'il pleuvra samedi dès quatorze heures, que la fête est maintenue et que l'équipe pourra s'abriter sous la halle. Enregistrez le modèle avec ces informations.

## Relire avant l'envoi

Revenez dans Messages et appliquez le modèle corrigé. Ouvrez l'aperçu de l'email. Vérifiez l'horaire et l'abri avant de décider de l'envoi. L'aperçu vous laisse encore le temps de relire.
