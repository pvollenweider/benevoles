# Jalons et pilotage de la préparation

**Identifiant stable :** `EVENT_MILESTONES`

## Démonstration

1. Ouvrir les jalons d’un événement actif.
2. Ajouter une échéance concrète.
3. Comparer un jalon dépassé, à venir et terminé.
4. Terminer puis rouvrir un jalon.
5. Montrer leur rôle dans le pilotage général.

## Résultat visible

- Les priorités restent proches du planning.
- Une échéance passée est clairement signalée.
- Une étape peut être rouverte sans la recréer.
