# Documentation de benevol.app

Une page par tâche, publiée sur le site à l'adresse `/doc/<nom-du-fichier>` (par exemple `revenir-sur-la-page-d-inscription.md` devient `/doc/revenir-sur-la-page-d-inscription`). Le fichier est la seule copie du contenu : la page du site le lit directement.

## Écrire une page

Chaque fichier commence par un en-tête court, puis par son titre `# ` (le seul de la page) :

```
---
roles: [benevole]
group: apres-inscription
order: 10
summary: Une phrase de 70 à 160 caractères, reprise comme description de la page.
related: [autre-page]
legacy: [benevole#ancienne-ancre]
aliases: [ancien-nom]
---

# Titre de la page
```

- `roles` : `admin` (organisateurs), `benevole` (bénévoles), ou les deux.
- `group` : un groupe de `DOC_GROUPS` dans `src/lib/doc-units.ts`.
- `order` : la position dans le groupe.
- `related` : les pages proposées sous « Voir aussi », par nom de fichier.
- `legacy` : les ancres des anciens guides (`/doc/benevole#…`) que cette page remplace. Quand une section quitte un guide, la page qui la reprend déclare son ancre ici : un lien vers l'ancienne ancre ouvre alors cette page (avec la même ancre si la page a un titre du même nom). Un test vérifie que chacune des 86 ancres d'origine (`src/lib/__tests__/fixtures/legacy-doc-anchors.json`, figées) est encore dans son guide ou reprise par une page.
- `aliases` : les anciens noms de la page, redirigés vers elle.
- `added`, `updated` (facultatifs, `AAAA-MM-JJ`) : la date d'ajout de la page, ou de sa dernière mise à jour qui mérite d'être signalée. La page porte alors « Nouveau » ou « Mis à jour » pendant 30 jours, sur la page, dans les listes et dans le menu latéral, puis plus rien. À renseigner à la main, et pas pour une simple correction : ni la date du fichier ni celle de git ne comptent. `new: false` retire l'indication avant la fin des 30 jours.

Les pages pour les bénévoles tutoient ; une page pour les deux rôles explique une fois, puis « Côté organisation » (vouvoiement) et « Côté bénévole » (tutoiement). Une vidéo au plus par page, sur sa propre ligne : `<!-- video: ID -->`. Un lien vers une autre page s'écrit par son fichier, `[titre](autre-page.md#ancre)`, et fonctionne ainsi sur GitHub comme sur le site.

Après avoir ajouté, renommé ou retiré une page, mettre à jour la liste ci-dessous : `npm run doc:index`.
